O botão Encerrar captura para a gravação imediatamente, mesmo que o Whisper ainda esteja trabalhando. O AEC pode reduzir o eco, mas não é garantia. A supressão automática ocorre somente para trechos muito semelhantes entre canais; falas misturadas ou simultâneas podem permanecer. Confira o diagnóstico antes de utilizar a transcrição. As falas simultâneas podem aparecer fora de ordem. A fila é mantida apenas nesta aba; não feche a página enquanto houver trechos pendentes. A inferência pode demorar mais que a duração do áudio. O filtro de silêncio é aproximado e pode deixar passar ruídos ou omitir fala baixa. Para segurança, o áudio não é enviado a uma API de transcrição.
